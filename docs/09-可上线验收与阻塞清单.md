3. **唯一硬阻断是 publishable key 还没填**。填进去（一个字符串）即可用真实库；
   在这之前页面会自动以「演示数据」运行，功能可点、数值不可信，界面上有明确标记。

### 指标口径（服务端实现，与 docs/01 §9 一致）

- `TL = Σ training_load`（按训练所在日，按组织时区切日）
- `CTL_t = CTL_(t-1) + (TL_t − CTL_(t-1))/42`；`ATL` 用 `/7`
- `ACWR(EWMA)`：λ=0.25 与 0.069 双 EWMA 之比
- `ACWR(rolling)`：需 7/7 与 ≥26/28 有效天才输出，否则**不写值**
- `TM = mean7/sd7`，`sd=0` 不输出；`TS = sum7 × TM`
- **缺测日直接跳过，不补 0**（`daily_metrics` 无行即缺测）

## 四、卡住 / 依赖外部条件（需要你提供，按影响排序）

| # | 事项 | 需要你做什么 | 影响范围 | 不给会怎样 |
|---|---|---|---|---|
| 1 | **publishable key** | Dashboard → Project Settings → API Keys → **Publishable key** → Copy（或 Connect → App Frameworks 整段复制），贴到 `prototype/env.js` 的 `SUPABASE_PUBLISHABLE_KEY`；本机也可在页面「数据源」里粘一次 | 全部真实读写 | 只能用演示数据，**注册/登录不可用** |
| 2 | **邮箱确认开关** | Authentication → Sign In / Providers → Email → 关闭 `Confirm email`（试点期） | 用户能否注册后立刻登录 | 注册成功但登录被拦；需用 `tools/accounts.mjs confirm` 手工确认 |
| 3 | SMTP（正式期） | 自备 Resend / SendGrid / 阿里云邮件推送的账号与 API Key | 确认邮件、找回密码 | 找回密码功能事实上不可用 |
| 4 | Edge Functions 部署 | Supabase Personal Access Token（或由你在 Dashboard 手工粘贴 4 个函数） | 服务端导出/删除通道、OAuth 回调 | 用户删除数据需人工处理（导出已用客户端方案兜住） |
| 5 | **境内服务器 + 域名 + ICP 备案** | 境内云账号、已备案域名、主体资质 | **能否公开上线**（合规硬阻断） | 只能内部试点，不能对外发布 |
| 6 | 手机号登录 / 微信登录 | 短信服务商签名与模板；微信开放平台 AppID | 登录方式 | 目前仅邮箱密码 |
| 7 | 设备厂商授权 | COROS / Garmin 开发者账号与 OAuth 凭据 | 自动同步训练 | 只能手动录入 / 文件导入 |
| 8 | 监控与备份 | Sentry DSN、备份保留策略确认 | 线上可观测性与恢复 | 出问题只能靠日志人工排查 |

> 上表 1 是唯一「给了就立刻可用」的项；2 决定注册体验；5 决定能不能对外。

## 五、已知限制（不是 bug，是这轮没做的）

1. **36 个页面里只有核心几页接了真实数据**：今日、教练看板（成员数/负荷/完整度已按真实成员现算）、成员档案、训练记录、审计、数据源面板。
   其余页面（周期计划、课库、VBT/跳跃分析详情、报告导出、设备中心、规则版本等）仍是**原型静态区块**，数值标注 DEMO。
   → 这些页面要接后端，属于下一轮工作，约 3–5 天。
2. **周期计划 / 规则引擎**：表结构里没有 `plan_blocks` / `rules`，页面展示的是口径说明与示例，不可写。
3. **实时推送**：Supabase Realtime 发布已开（8 张表），但前端仍用「同步一次」而非订阅；接订阅约半天。
4. **删除账号**：需要 Edge Function 部署（阻塞项 4）；目前只能人工按 `audit_logs` 定位后删除。
5. **报告导出 PDF、分享链接**：未做。
6. 免费版闲置 7 天自动暂停，需定时访问或升配。
