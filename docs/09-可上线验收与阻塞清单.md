# 第三世界 · 可上线验收与交付清单

更新时间：2026-11-14 04:20 GMT+8
目标口径：**真实用户可注册、可登录、可正常使用核心流程**（运动员 / 教练双角色），
并且**后端能算的都在后端算完**，前端只负责显示。

---

## 一、结论先说四句

1. **核心闭环在真实数据库上跑通并逐条验证**：注册 → 开通（个人空间 / 建组织 / 邀请码）→ 记录训练 / 自评 / 跳跃 / VBT → 服务端自动算全部指标 → 教练看到队员数据 → 别人看不到 → 可导出、可删除、可注销。
   证据：`tools/test-flows.mjs` **85/85 通过**，`tools/audit-db.mjs` **28/28 通过**，残留 0。
2. **计算全部在库里**：负荷族、跳跃族、速度族、恢复族、就绪度、计划执行度、团队聚合，一律是 Postgres 函数 + 触发器，前端不参与运算（只渲染 RPC 返回的 jsonb）。
3. **计划 / 课库 / 规则版本这三张"缺失的表"已经补齐**，可写、有 RLS、有审计，不再是静态示例。
4. **唯一硬阻断仍是 publishable key**。填一个字符串即可切到真实库；在此之前页面以「演示数据」运行，功能可点、数值不可信，界面有明确标记。

### 口径汇总（全部服务端实现）

- `TL = Σ training_load`（按组织时区切日）；`load.week = Σ7 日`
- `CTL_t = CTL_(t-1) + (TL_t − CTL_(t-1))/42`；`ATL /7`；`TSB = CTL_(t-1) − ATL_(t-1)`
- `ACWR(EWMA)`：λ=0.25 / 0.069 双 EWMA 之比，**状态量，休息日延续**
- `ACWR(rolling)`：需 7/7 与 ≥26/28 有效天才输出
- `TM = mean7/sd7`（sd=0 不给）；`TS = sum7 × TM`
- 跳跃 `h = 9.81·t_f²/8`；`RSI = h(m)/t_c(s)`；`PPO = 60.7h + 45.3m − 2055`（Sayers）
- VBT `VL% = (1 − MPV/MPV_best)×100`；`功率 = load·9.81·MPV`；1RM 由 `v = a + b·load` 在 `v=0.3` 处外推（n≥3、b<0）
- `lnRMSSD = ln(RMSSD)`；基准 = 7 日均值；`SWC = 0.5·SD`；`z = (x−基准)/SWC`
- `睡眠债 = max(0, 7×目标 − Σ7 日 TST)`
- `就绪度 = 负荷分×0.35 + HRV分×0.35 + 睡眠分×0.30`（缺分量按比例重分配；全缺返回 null）
  - 负荷分：ACWR 在 [0.8, 1.3] 得 100；低于 0.8 最低 60；高于 1.3 按 1.5 线性扣到 0
  - HRV 分：`50 + z×25`（+2 SWC = 100，−2 SWC = 0）
  - 睡眠分：`TST / 目标 × 100`（封顶 100）
- 阈值不是硬编码：来自 `rules.payload`（`arc_active_rule()`），换版本只改一行
- **缺测一律不补 0**：TL 无行即缺测；状态量靠「延续」而不是「填 0」

## 六、已知限制（不是 bug，是这轮没做的）

1. **约 24 个页面仍是原型静态区块**：今日、训练概览、周期计划、课库、规则版本、教练看板、成员档案、训练记录、审计、VBT 分析、跳跃表现、报告与导出、数据源面板已接真实数据；
   仍有氧与功率、测试采集（lab/*）、设备中心、导入、数据质量、合规等页面展示 DEMO 区块——但每页现在都会明确标注数据来源（真实 / DEMO），不会混着用。
2. **图表序列与「服务端唯一计算」的关系**：`A.SRV` 直读 `daily_metrics` 的 ctl/atl/tsb/acwr/tm/ts，前端不递推；
   仅演示模式（无 key）仍用前端 `computeLoad()` 生成假曲线。
3. **计划页仍缺写入口 UI**：`arc_assign_session` / `arc_activate_rule` / `arc_seed_default_rules` 已有 RPC 与权限校验，
   界面还只读不写（排课、发版需要教练点两次确认的交互，属于下一轮）。
4. **实时推送**：Realtime 发布已开（8 张表），前端仍是「同步一次」而非订阅；接订阅约半天。
5. **PDF 报告与分享链接**：未做，需要 Edge Function 渲染（见 `docs/10` 第 4 项）。
6. 免费版闲置 7 天自动暂停，需定时访问或升配。
