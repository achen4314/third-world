## 1. 训练模块（导航「训练」）

**唯一负荷输出：`TL` 与 `ACWR`。** CTL / ATL 是 ACWR 的内部状态量，只在「分析 · 负荷与周期」里作为口径依据出现，不作为训练模块的输出项。测试项目一律不写进训练负荷。

### 1.1 页面清单（6 页）

| 页面 | 内容 |
|---|---|
| `train` 训练概览 | 本周累计 TL、当前 ACWR、计划完成率、缺测天数；近 14 日 **TL 柱状图**、近 28 日 **ACWR 折线图**；周期块、近期训练 |
| `train/calendar` 训练日历 | 近 14 日 TL、近 28 日 ACWR、周期阶段目标周 TL、训练记录列表 |
| `train/session` 单次训练详情 | 时长、本次 TL、sRPE；本课字段原样、TL 计算口径、分段明细核对 |
| `train/plan` 周期计划 | 阶段目标 TL、计划阶梯、规则依据 |
| `train/library` **训练方案库** | 8 类训练类型、8 套预设搭配方案、自行搭配入口、教练下发的结构化课 |
| `train/goals` 比赛与目标 | 目标赛事与个人最好成绩 |

### 1.2 可选训练类型（8 种，每段独立选择）

| 类型 | 说明 |
|---|---|
| 力量 | 抗阻 / 爆发力 / 器械 |
| 跑步 | 轻松跑 / 节奏 / 间歇 |
| 骑行 | 耐力 / 阈值 / 功率 |
| 游泳 | 技术 / 有氧 |
| 球类 | 专项 / 对抗 / 技战术 |
| 功能性 / 体能 | 循环 / 核心 / 移动 |
| 恢复 / 低强度 | 拉伸 / 低强度活动 |
| 其他 | 自行注明的训练 |

**不含「测试」**——测试项目全部在测试模块。

### 1.3 自行搭配方案

- **分段搭配器**：一次训练 1–8 段，每段独立选「类型 / 分钟 / RPE(0–10)」，顺序即执行顺序；可随时增、删、清空。
- **预设结构方案（8 套）**，载入后可逐段修改：

| 方案 | 结构 | 段数 | 建议总时长 |
|---|---|---|---|
| 力量主课 | 恢复 10′ + 力量 45′ + 恢复 10′ | 3 | 65 min |
| 有氧耐力 | 恢复 10′ + 跑步 50′ + 恢复 10′ | 3 | 70 min |
| 速度间歇 | 恢复 15′ + 跑步 30′ + 恢复 10′ | 3 | 55 min |
| 骑行阈值 | 恢复 10′ + 骑行 60′ + 恢复 10′ | 3 | 80 min |
| 恢复日 | 恢复 30′ | 1 | 30 min |
| 综合体能 | 恢复 10′ + 功能性 25′ + 球类 25′ + 恢复 10′ | 4 | 70 min |
| 游泳技术 | 恢复 10′ + 游泳 45′ + 恢复 5′ | 3 | 60 min |
| 赛前激活 | 恢复 15′ + 球类 20′ + 恢复 10′ | 3 | 45 min |

> 这些是**结构模板**，只给「类型 + 建议时长 + 建议 RPE」，不是已发生的训练，不含任何成绩或负荷数值，也不写入数据库。实际值由用户填写，保存后才产生 TL。

- **我的方案**：把当前搭配命名后存到本机（localStorage），下次可直接载入或删除；不新建数据库表。
- **可选总距离**（km），留空即「未记录」。

### 1.4 计算口径

```
每段 TL   = 该段 RPE × 该段分钟
本次 TL   = Σ 每段 TL
总时长    = Σ 每段分钟
写入 RPE  = round(本次 TL / 总时长)      # 加权平均，供单字段存档
sport     = 时长最长那一段的类型
ACWR      = 服务端按日负荷重算（EWMA），前端只读不重算
```

保存时写 **一条** `activities` 记录，分段明细放在该行已有的 `raw` jsonb 字段：
`{"schema":"training.segments.v1","plan":<方案名|null>,"segments":[{type,dur,rpe},…]}`。
不新建表、不改迁移、不删任何既有数据。

## 2. 测试模块（导航「测试」）

**与训练负荷完全隔离**：测试记录不参与 TL 与 ACWR 计算，也不出现在训练方案库、训练记录或训练图表里。

### 2.1 页面清单（7 页）

| 页面 | 内容 |
|---|---|
| `lab` 测试概览 | 测试入口与近期测量状态 |
| `lab/vbt` VBT 采集 | 每次重复的速度、负荷-速度剖面、1RM 估计、速度损失、杠铃轨迹 |
| `lab/jump` 跳跃采集 | CMJ / SJ / DJ / RSI 10-5 的高度、腾空/触地时间、RSI |
| `lab/sprint` 冲刺与变向 | 分段计时、变向力学 |
| `lab/screen` 活动度与问卷 | 关节活动范围、主观状态 |
| `lab/history` 测试历史与对比 | 同条件前后对比 |
| `lab/calibration` 标定与动作库 | V1RM 标定、计算参数版本 |

### 2.2 测试项目选项（4 组）

| 组别 | 具体项目 |
|---|---|
| 跳跃 | CMJ、SJ、摆臂 CMJ、DJ 跳深、RSI 10-5、立定跳远、单腿不对称 |
| VBT | 杠铃速度、负荷-速度剖面、1RM 估计、速度损失、杠铃轨迹 |
| 冲刺 / 变向 | 5-0-5、5+5、V-Cut、Illinois、分段冲刺、水平 FVP |
| 筛查 | 踝背屈 ROM、Nordic 断点角、Wellness 问卷、力-时间曲线 |

跳跃采集的即时选项：类型 `CMJ / SJ / DJ 跳深 / RSI 10-5`、视频帧率（可选）、腾空时间、触地时间（DJ 必填）；高度按 `h = g·t²/8`，RSI 缺触地时间就不给值。

## 3. 分离如何落地

| 改动 | 效果 |
|---|---|
| 记录浮层拆成 `scope=train` / `scope=test` | 训练浮层只有「训练 / 每日自评」，测试浮层只有「跳跃测试」；各自顶部声明边界，可一键互跳 |
| 顶栏「＋ 记录训练」/ 测试页「＋ 记录测试」 | 两个独立入口，不再共用一个含测试页签的浮层 |
| 训练页 actions 改为 `act: arc-record`；测试页改为 `act: arc-test-record` | 训练页不再打开测试协议选择 |
| `newtest` Sheet 更名「选择测试项目」 | 只从测试模块进入 |
| 训练方案库删掉测试协议网格与测试类示例课 | 课库只剩训练 |
| 单次训练详情删掉 TSS 指标与 VBT 关联卡片 | 只保留 TL 相关口径 |
| 训练图表换成 TL + ACWR | 不再画 CTL / ATL |
| 今日页三个入口改为 训练 / 测试 / 数据 | 不再直接塞两个测试采集入口 |
| 演示数据里的「跳跃测试 + 活动度筛查」改为训练项 | 未登录时也不会在训练列表里看到测试 |

### 实机抓到并修掉的两个发布链路 bug

| 现象 | 根因 | 修复 |
|---|---|---|
| 测试页点「＋ 记录测试」，页面被弹回今日页、浮层不出现 | 页面级 `actions` 已支持 `act`，但 **hero 区块**的 `actions` 渲染仍只认 `sheet` / `route`；遇到 `act` 时生成 `data-act="nav" data-route="undefined"` | hero 与页面级统一为 `act / sheet / route` 三分支，并加防回归断言 |
| 改完代码、升了 `?v=` 版本号，浏览器仍跑旧 JS | `sw.js` 里 `caches.match(req, { ignoreSearch: true })` **忽略查询串**匹配缓存，把 `?v=` 版本号整个废掉；还带 stale-while-revalidate，回访用户一直拿旧外壳 | 静态资源按完整 URL 精确匹配；HTML 导航改 **network-first**；业务与鉴权请求仍不缓存 |

第二个不只影响本地调试：**每次发新版，已访问过的用户会继续加载旧 JS**，界面改动看起来「没生效」。
已把「不得使用 `ignoreSearch`」「HTML network-first」写进 `verify-modules.mjs` 的防回归断言。

**验证边界（如实说明）**：浏览器原生 `<select>` 的下拉是操作系统层弹窗，自动化无法用键盘/坐标选值，
所以「载入方案」按钮的端到端点击没有实测；8 套方案已确认渲染在下拉中，
其结构与 TL 公式由 `verify-modules.mjs` 静态验证。其余增删改、切换、预览均已实测。
本次浏览器操作**只登录并查看界面，没有点「保存训练」/「保存测试」，未写入任何业务数据**。

**没有改动**：数据库表结构、迁移、RLS 策略、既有业务数据、认证配置、域名解析与服务器。
