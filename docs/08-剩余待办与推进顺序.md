## P1 · 决定"像不像一个真产品"

### P1-1 指标计算落服务端（L）

- TL / ACWR(EWMA) / HRV 基线 / 睡眠分 / 单调性- Strain 目前只在前端 `live.js` 里算，刷新即丢。
- 落法：一个定时 Edge Function（或 `pg_cron`）每日算完写 `daily_metrics`，`calc_version` 记录口径版本，`metric_registry` 是唯一公式源。
- **口径必须可回溯**：同一天用 v1.0 与 v1.1 算出的值不能互相覆盖，用 `calc_version` 区分。
- 验收：连续 7 天跑批，`daily_metrics` 每天 30 条（22 core + 8 vendor_aligned 分开写），任意一天能解释"这个 ACWR 是哪几个数算的"。

### P1-2 Realtime 替换假 SSE（M）

- 现在 `live.js` 是 1 Hz 定时器造的假数据。切到 `supabase.channel().on('postgres_changes')`，保留"无网络时回退到模拟"的开关，方便演示。
- 验收：两台设备同时打开，A 端录入一条测试，B 端 2 秒内自己出现，不需要刷新。

### P1-3 真实设备接入（L，依赖外部）

- 需要：Enode / Garmin 的 client id / secret 与 scope；没有就只能停在"代码就绪、凭据缺失"。
- `device-oauth-start` → 厂商授权 → `oauth-callback` → 令牌加密落 `device_credentials` 这条链已在代码里通了，缺的是真实凭据与 token 刷新任务。
- 验收：绑定一次 Garmin 账号，拉回最近 7 天活动，`activities.source='api'`，`external_id` 去重不重复。

### P1-4 报告导出（M）

- `/report` 页现在只有 UI。需要导出 PDF（训练周报）与 CSV（原始明细）。
- 走 `exports` 桶 + 签名链接，和个人信息导出用同一套路径约定，避免两套权限逻辑。
- 验收：导出的 CSV 用 Excel 打开中文不乱码（UTF-8 BOM），PDF 里图表是矢量不是截图。

### P1-5 合规闭环（M）

- 隐私政策版本化 + 同意流转 UI（`consents` 表已就绪，缺前端）；注销流程（`delete-athlete-data` 已就绪，缺入口与二次确认文案）。
- 未成年人：`app_users.is_minor` / `guardian_consent_at` 字段已在，缺监护人同意流程。
- 验收：新用户首次登录必出同意页；撤回同意后相关处理停止且可验证；注销走完 `dry_run → confirm` 两步。

## P2 · 上线前才需要，但不做会卡住

| # | 项 | 规模 | 说明 |
|---|---|---|---|
| P2-1 | **境内区域迁移** | L | ICP 备案硬门槛。库在 `us-east-1` 无法备案，须迁 `ap-northeast-1` 或境内云。迁移前先做数据出境评估（健康数据属敏感个人信息） |

## 建议推进顺序（按依赖，不按喜好）

```
第 1 步（今天）      P0-5 改密码  ──┐
第 2 步（并行）      P0-4 部署函数 ─┴─→ 这两步都只卡凭据，不卡代码
第 3 步              P0-1 接入层 ────→ P0-2 读路径 ───→ P0-3 写路径
                                      （读写要分开做：先只读上线，写操作最后开，
                                        出问题能立刻回退到 DEMO 而不影响已有数据）
第 4 步（可与 3 并行） P1-1 指标计算落库   ← 与前端读路径互不阻塞，但必须在"真实数据进来"之前跑通
第 5 步              P1-2 Realtime ────→ P1-5 合规闭环
第 6 步              P2-5 CI 越权回归  ──→ P2-6 E2E
第 7 步（最晚启动）   P2-1 迁境 + P2-2 备案   ← 周期最长，与其他技术工作无依赖，应最早并行启动
第 8 步              P1-3 设备接入  ────→ P1-4 报告导出   ← 依赖外部凭据与真实数据，放最后
```

三条排序理由：

1. **P0-5 最先**：密码已泄露，其他工作做再多，这个口子都在。
2. **读写分离推进**：先只读上线，能立刻看到"真实数据 + 真实权限"是否对得上；写路径最后开，避免错误数据污染库、也避免回退困难。
3. **P2-1/P2-2 提前并行**：备案与迁移是日历时间，不是工作量，越晚启动越可能成为唯一阻塞项。
