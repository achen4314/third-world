## 1. 代码修复（本轮已改，已回归）

| 编号 | 问题 | 改法 | 位置 |
|---|---|---|---|
| F-1 | **`fetch` 无超时**：任一个请求卡在 TCP 上，整页永远停在「同步中」，用户只看到一个转不完的骨架屏 | 每个请求 15s `AbortController` 超时，超时抛「请求超时（15 秒无响应）」；网络错误与超时区分文案 | `supabase-client.js` `http()` |
| F-2 | **今日/周计划走 UTC**：`p_date: null` → 库端 `current_date` 是 UTC，北京 0–8 点算成「昨天」 | 新增 `localToday()`（不用 `toISOString`），`arc_daily_summary`、`arc_week_plan`、`arc_assign_session`、CSV 文件名四处统一传本地日期 | `supabase-client.js` / `app.js` |
| F-3 | **401 仍会降级成演示数据**：与上轮「失败不降级」原则矛盾 | `clearSession(true)` 保留上次数据 + 标 `needAuth`；无数据则走错误态。**任何路径都不再 `restoreDemo()`** | `supabase-client.js` |
| F-4 | 图表空数组 → `iw/n` = Infinity → 整块 SVG 白屏 | 入口判空返回显式空态「本期没有数据 / 暂无指标」 | `app.js` `svgBars` / `svgGauge` |
| F-5 | `resize` 无节流：拖动窗口触发数十次全量重建 SVG，动画反复重放 | 150ms 去抖 + 每帧一次 + `mountCharts(skipSame)` 尺寸未变则跳过 | `app.js` |
| F-6 | 登录失效时页面无明确指引 | 顶栏与页面标签增加「登录状态已失效 · 请重新登录」态 | `app.js` `dataChip` / 顶栏 |

**回归**：`test-flows` **91 通过 / 0 失败**，残留 0；浏览器实机加载验证通过（真实库：ACWR 0.70、就绪度 80、状态「已同步」）。
