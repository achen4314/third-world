## 3.1 核查方法与覆盖

- **方法**：无头 Chrome + CDP `Runtime.evaluate` 确定性断言（脚本已归档 `tools/audit.mjs`），断言结果为布尔值，报「通过」前先自证期望值，避免假阳性 / 假阴性。首轮 72 项断言出现 3 项异常，经定点复核判定 **3 项为断言本身写错（假阴性）**，并额外暴露 **4 项真实缺陷**；修复后复验 **76 项**。
- **覆盖枚举**：17 类 `data-act` 交互、13 类浮层、5 类图表渲染器（`line / bars / scatter / gauge / stack`）、12 个含图表界面共 16 个图表位、1 个 28 日热力网格、18 个 `metric_id`、18 项算法断言、36 条路由、5 种状态反馈、8 类边界场景。
- **线上复验**：部署后以真实浏览器加载线上链接，今日页与分析页均完整渲染，无 JS 异常。

**结论列取值**：`通过` / `异常`（已修复闭环）/ `待确认`（非缺陷，依赖生产接入）。通过项的「问题位置 / 影响范围 / 优先级」记为「—」，「修复与复验」记为「无需修复 · 已复验通过」。
