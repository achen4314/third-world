# ARC 训练 · 交互流程与视觉设计规则（v1.0）

> 本文件是 `../prototype/` 的**设计源文件**：原型里每个数值都应能在此查到依据。遵循 Apple HIG（2026-09 版）静态规范与 *Designing Fluid Interfaces* 动效体系；已按 IDE 浅色主题落地，同时提供深色变体。

---

## 1. 先定原则（八条，逐条对应本产品的取舍）

| HIG 原则 | 本产品的具体裁决 |
|---|---|
| Purpose / 挣得位置 | 今日页每个元素必须支撑「今天该练什么」这一结论；无法回答的元素移到分析/数据页 |
| 层级清晰 | 层级 = 字号 + 字重 + 行高组合；强调优先加字重，不加装饰线 |
| 渐进披露 | 口径/阈值/标定参数收进 Sheet；主屏只显示当前生效值 |
| 一致性即信任 | 三端同语义导航、同组件、同数据；看起来一样的卡片行为必须一样 |
| 不单靠颜色 | 任何状态色必配文字标签或图标；缺测用「—」不用灰点 |
| 材质服务层级 | 毛玻璃只用于 Sidebar / Tab Bar / 顶栏；内容卡片一律实色 |
| 反馈即时 | 按下即反馈（pointer-down），不等松手；同步/保存均有即时 HUD |
| 无障碍是底线 | 44×44 点击目标、4.5:1 对比、`prefers-reduced-motion`、Dynamic Type 不截断 |

## 2. 视觉令牌（可直接映射为 Design Token / SwiftUI / CSS 变量）

### 2.1 字体（映射 iOS Dynamic Type 默认档）

| Token | 字号 / 行高 / 字重 | 用途 |
|---|---|---|
| `largeTitle` | 34 / 41 / 400（强调 700） | 今日页主状态数值、Mac 一级标题 |
| `title1` | 28 / 34 / 400 | 页面主标题（Mac / iPad） |
| `title2` | 22 / 28 / 600 | 卡片组标题 |
| `title3` | 20 / 25 / 600 | 二级页标题（iPhone） |
| `headline` | 17 / 22 / 600 | 列表行标题、指标名 |
| `body` | 17 / 22 / 400 | 正文 |
| `callout` | 16 / 21 / 400 | 次要正文 |
| `subhead` | 15 / 20 / 400 | 辅助说明、卡片副标题 |
| `footnote` | 13 / 18 / 400 | 口径注释、证据编号 |
| `caption` | 12 / 16 / 500 | 芯片文字、轴标签（**最小 11px，不再小**） |
| `metric` | 40 / 46 / 650，tabular-nums | 关键指标数值（字距 −0.02em） |

字体栈：`-apple-system, "SF Pro Display", "SF Pro Text", "PingFang SC", "Helvetica Neue", sans-serif`。数字统一 `font-variant-numeric: tabular-nums`，避免曲线图与表格跳动。中文与拉丁混排不加额外字距；字距随字号自动收紧，禁止全站固定 letter-spacing。

### 2.2 颜色（浅色为默认，深色为等值变体）

**中性层**

| Token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `bg` | `#F5F5F7` | `#0B0B0D` | 窗口底色 |
| `surface` | `#FFFFFF` | `#1C1C1E` | 内容卡片（实色） |
| `surface-2` | `#FAFAFC` | `#242426` | 卡片内分区 |
| `separator` | `rgba(60,60,67,.12)` | `rgba(255,255,255,.12)` | 1px 分隔 |
| `text-1` | `#1D1D1F` | `#F5F5F7` | 主文字 |
| `text-2` | `rgba(60,60,67,.60)` | `rgba(235,235,245,.60)` | 次要文字 |
| `text-3` | `rgba(60,60,67,.38)` | `rgba(235,235,245,.38)` | 三级 / 占位 |
| `chrome` | `rgba(255,255,255,.72)` | `rgba(28,28,30,.72)` | 导航层材质 |

**语义色（一种颜色只表达一种含义，且必配文字或图标）**

| 颜色 | 浅 / 深 | 唯一含义 | 配套标识 |
|---|---|---|---|
| 蓝 `#007AFF` / `#0A84FF` | 可交互 / 选中 | 「查看趋势」「保存」「选中态」 | 箭头或填充按钮 |
| 靛 `#5E5CE6` / `#7D7AFF` | 教练工作台 | 切换工作区后的顶栏与侧栏 | 「教练工作台」文字 |
| 橙 `#FF9500` / `#FF9F0A` | 需关注 | ACWR 越界、待审批、待标定 | 「需关注」标签 + ⚠ 图标 |
| 红 `#FF3B30` / `#FF453A` | 破坏性 / 数据无效 | 解绑、删除、质量不合格 | 「删除 / 无效」文字 |
| 绿 `#34C759` / `#30D158` | 完成 / 已同步 | 同步成功、计划完成、设备在线 | ✓ 图标 |
| 灰阶 1–6 | 信息层级 | 缺测、禁用、占位 | 「—」文本 |

> 曲线配色不承担状态含义：`CTL` 蓝、`ATL` 橙灰、`TSB` 靛、`ACWR` 蓝绿，均配图例文字；**颜色不表示好坏**，好坏由规则文字与数值区间说明表达。这一条直接避免 COROS 式「颜色等级即结论」。

**对比度**：正文 ≤17px ≥4.5:1；≥18px 或 Bold ≥3:1；图形/控件边界 ≥3:1。`text-2` 在 `surface` 上约 5.2:1，满足。深色模式为独立设计，不做简单反色。

### 2.3 间距、圆角、阴影

- 8pt 栅格：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48`；页面左右边距 **20px（移动端）/ 24px（iPad）/ 32px（Mac）**。
- 正文最大可读宽度 680px；Mac 三列时每列不小于 300px。
- 卡片圆角 **18px**（iPhone 卡片 16px），芯片 8px，按钮 12px，Sheet 顶部 24px。
- 卡片阴影：`0 1px 2px rgba(0,0,0,.04), 0 8px 24px rgba(0,0,0,.04)`；深色改为内描边 `1px rgba(255,255,255,.06)`，不叠加更重的阴影。
- 点击目标 **44×44px**（桌面最小 20×20px，但本原型统一 ≥32px，主要操作 ≥44px）；带边框控件四周 ≥12px，无边框控件可见边缘 ≥24px。
- 列表行高 ≥44px；卡片内边距 16/20px。

### 2.4 材质配方（仅控件层）

```css
.chrome {
  background: rgba(255,255,255,.72);            /* dark: rgba(28,28,30,.72) */
  -webkit-backdrop-filter: blur(20px) saturate(180%);
  backdrop-filter: blur(20px) saturate(180%);
  border-top: 1px solid rgba(255,255,255,.4);  /* 亮顶边 = 光线打在材质上 */
}
/* 内容卡片内部一律实色，不再叠 blur；轻材质上不叠轻材质 */
```

富媒体/图表上方的 clear 变体需加 35% 黑暗化层。`prefers-reduced-transparency: reduce` 时材质退化为实色。

## 3. 跨端一致性规则（iPhone / iPad / Mac）

**同一套信息架构，只改三件事：导航控件形态、列数、边距。** 页面标题、口径芯片、卡片内容、跳转目标在三端完全一致。

| 维度 | iPhone（390×844） | iPad（1024×720 横屏） | Mac（1440×900 窗口） |
|---|---|---|---|
| 一级导航 | 底部 Tab Bar（5 项，高 49px + 安全区 34px） | 左侧 Sidebar 200px | 左侧 Sidebar 240px + 窗口交通灯 |
| 工作区入口 | 顶栏头像菜单 →「教练工作台」 | Sidebar「工作区」分组 | Sidebar「工作区」分组 + 顶栏可见按钮 |
| 内容列数 | 1 列 | 2 列（主视图跨 2 列） | 3 列（主视图跨 2 列，侧栏卡 1 列） |
| 页面标题 | `title3` 20px，紧凑 | `title1` 28px | `title1` 28px |
| 数值卡 | 2 列小卡 / 1 列大卡 | 4 列 | 4–6 列 |
| 图表高度 | 180–200px | 240px | 260–300px |
| 弹层 | 全宽 Sheet，从底部升起，`presentationDetents` 中/大 | 居中卡片 Sheet，宽 560px | 居中卡片 Sheet，宽 620px；Popover 锚定触发元素 |
| 面包屑 | 隐藏（用返回按钮） | 显示 | 显示 |
| 键盘 | — | ⌘K 命令面板 | ⌘K 命令面板、Esc 关闭浮层 |
| 安全区 | 顶部 59px / 底部 34px，内容不越界 | 四边 24px | 窗口内 0，交通灯区留 72px |

**Size class 决策，不按设备名决策**：`compact` → Tab Bar + 单列；`regular` → Sidebar + 多列。原型用平台切换模拟三种 size class；真实实现用 SwiftUI `@Environment(\.horizontalSizeClass)` / `NavigationSplitView`。

**跨端禁止项**：不得为 Mac 另造一套菜单名称；不得在 iPhone 隐藏某个二级页（只改为更深一层的 Sheet）；不得因屏幕大而把两页内容合并到一屏。

## 5. 动效规则（Fluid Interfaces）

**唯一允许动画的属性：`transform` 与 `opacity`。** 不改变布局属性，避免掉帧与跨端不一致。

| 场景 | 参数 | 说明 |
|---|---|---|
| 默认 UI 弹簧 | damping 1.0（bounce 0），response 0.30–0.40s；Web `cubic-bezier(.22,.61,.36,1)` 400ms | 页面切换、卡片展开 |
| 动量 / 甩动弹簧 | damping ≈0.8（bounce 0.2），duration 0.40s | 仅 Sheet 拖拽甩动、可拖拽图表 |
| Sheet 进出 | 0.8 阻尼 / response 0.3；**进出同路径**，从触发元素锚定方向展开 | 关闭时沿原路径收回 |
| 按压反馈 | `:active { transform: scale(.97) }`，100ms ease-out，由 `pointerdown` 触发 | 按下即反馈，不等 `click` |
| 页面进入 | 内容 `translateY(8px) + opacity 0 → 1`，卡片按 24ms 递进 stagger | 最多 6 张，避免长串延迟 |
| 图表首次绘制 | 路径 `stroke-dashoffset` 由满到 0，420ms；柱高从 0 起 | 数据更新时从当前值续播，不跳回 0 |
| 数值变化 | 数字滚动 280ms（tabular-nums 防抖） | 不可计算 →「—」时直接交叉淡化，不滚动 |
| 边界 | 橡皮筋回弹，不硬停 | 列表触底 / Sheet 下拉 |
| 速度交接 | 拖拽松手时落点 `current + (v/1000)·d/(1−d)`，`d≈0.998`，再把速度交给弹簧 | 仅甩动关闭 Sheet 时使用 |
| 可打断 | 任何动画任意时刻可被抓取、反转、重定向，从**实时屏幕值**起播 | 用 Web Animations API 读当前 computed transform，不从 0 重播 |

**减弱动效**：`@media (prefers-reduced-motion: reduce)` 下所有位移动画改为 180ms 交叉淡化，取消 stagger、数字滚动与路径绘制；弹簧手势直接跳到终点但保留状态反馈。

**必备 media queries（原型已写入）**：`prefers-color-scheme: dark`、`prefers-reduced-motion: reduce`、`prefers-reduced-transparency: reduce`、`prefers-contrast: more`（近实色背景 + 明确边框）。

## 6. 关键交互流程

### F-A 设备配对与同步（O2）

```
数据页·设备中心 →「＋ 配对设备」
  → [1 扫描] 列出附近 BLE 广播（名称 / RSSI / 服务 UUID），未授权协议标注「需授权」而非伪造可用
  → [2 协议确认] 显示标准服务 UUID（HR 0x180D / CPP 0x1818 / FTMS 0x1826 / RSC 0x1814）与将订阅的 characteristic
  → [3 标定] 采样率、单位、安装位置；IMU 额外登记静止段重力估计与 ZUPT 阈值（留空=未标定，不默认填值）
  → [4 完成] 写入 device 记录 → 设备卡就地出现（绿点 +「已连接」）→ Toast「已连接，可撤销」
失败分支：权限未授予 → 就地说明 +「前往设置」；断连 → 橙标「重连中」+ 离线缓存队列计数；真机字节布局差异 → 标记 `quality_flag=suspect` 并进数据质量页，不静默丢弃
```

### F-B VBT IMU 拉取 / 手填双通道（O4 / O3）

```
测试·VBT 采集 → 数据源分段控件 [ IMU 实时 | 文件拉取 | 手动填入 ]
  实时：订阅通知 → 每次重复就地生成速度卡（MCV/MPV/PV）+ 实时 VL% 进度
  文件拉取：选 CSV/JSON → 预览前 5 行 → 字段映射（ts_ms/ax/ay/az/gx/gy/gz/load_kg/exercise）
            → 校验采样率与单位 → 显示「将写入 source=import」→ 确认
            → 后台处理链（去重力 → 低通 → 积分 → ZUPT → 重复切分）→ 中间结果可下钻
  手动填入：exercise / load_kg / rep_index / mpv_or_mcv / velocity_loss_pct / method=manual
            → 右侧**实时按公式预览** VL% 与组内速度损失；写入 source=manual
两条通道在计算时**互斥筛选**，不合并；结果页常驻「当前来源：import / manual」并可一键切换对比
保存 → Toast + 结果卡就地更新 → **不跳页**，保证连续测试不被打断
```

### F-C 跳跃测试（O5 → lab/jump）

```
＋ 新建测试 → 协议网格（CMJ / SJ / 摆臂 CMJ / DJ / RSI 10-5 / 立定跳远 / 单腿）
  → 录入通道 [ 视频帧标记 | IMU | 手填 ]
      视频：必须登记 fps（未填则结果不可计算，不猜测 240fps）；标记起跳帧与落地帧
      IMU ：冲击信号切分腾空/接触
      手填：腾空时间 t_f、接触时间 t_c、地面/鞋/测试时间备注
  → 即时结果：h = 9.81·t_f²/8、RSI = h/t_c、峰值功率（Sayers，系数从配置读取）
  → 同场次 SJ 与 CMJ 齐备才显示「牵张-缩短循环利用率」，否则显示「—（缺少 SJ）」
  → 保存 → 测试历史可同条件对比；条件不同时对比开关置灰并说明原因
```

### F-D 指标下钻（O1，全站统一组件）

```
任意指标卡「口径」→ Sheet
  ├ 当前值 / 单位 / 时间戳
  ├ 公式原文 + 公式版本号（如 TL-A v1.2 / ACWR-EWMA v1.0）
  ├ 窗口（单次 / 7 日 / 28 日 / 42 日）+ 有效天数规则
  ├ 输入字段清单 + 当前输入值
  ├ source / quality_flag / 证据编号 E1–E14
  ├ 原始样本表（前 N 行 + 「查看全部」）
  └ 若不可计算：明确原因（有效天数不足 / sd=0 / 无功率数据 / 未标定），不显示 0
```

### F-E 今日主状态与周期建议（O7）

```
每日 04:00（本地时区）由规则引擎生成：
  输入 CTL 斜率、ACWR(EWMA)、TSB、TM/TS、7 日有效天数、HRV 基线偏离、TST
  → 命中规则 R-xx → 输出【一句结论 + 三条依据 + 一个建议动作】
  → 「查看依据」展开每条规则的输入值、阈值、版本号与可调整参数
  → 「应用为周期块」→ train/plan 预填目标日 TL，**需二次确认**才写入
任何输入不足 → 结论降级为「数据不足，需补充 3 天负荷记录」，不生成建议；不输出黑盒分数
```

### F-G 权限与工作区切换（O8 / J22）

```
顶栏「教练工作台」→ 切换工作区 → 清空运动员区导航栈 → admin/overview
  → 顶栏常驻当前角色；O8 可切换角色演示
  → 权限矩阵重算可见模块：无权限页显示**锁定态 + 原因**，不静默隐藏
  → 所有写操作经服务端 RBAC；前端仅呈现
```

## 7. 文案与状态规则

- 缺测一律显示 **「—」**，并在下钻里给原因；禁止 `0`、`--`、`N/A`、估算值。
- 不可计算统一表述：**「不可计算 · 原因」**（如「不可计算 · 7 日窗口有效天数 5 < 7」）。
- 指标卡三枚芯片固定顺序：`口径 / 窗口 / 来源`，来源值域 `device | api | import | manual`。
- 不使用「状态良好 / 状态差」这类无依据结论；改为「依据 R-04：ACWR(EWMA) 1.18，在 0.8–1.3 区间内」。
- 不出现医学诊断措辞；睡眠与 HRV 页脚固定：「本页为可解释维度，不用于诊断」。
- 破坏性操作按钮必带对象名：「解绑 VBT IMU · imu-001」而非「确定」。
- 原型所有数值区域常驻 `DEMO 演示数据` 标记。

## 8. 无障碍与验收清单

- [ ] 所有可点元素 ≥44×44px，图标按钮有 `aria-label`
- [ ] 文字对比度 4.5:1（小字）/ 3:1（大字与图形）
- [ ] 不单靠颜色传信息，状态必配文字或图标
- [ ] `prefers-reduced-motion` / `prefers-color-scheme` / `prefers-reduced-transparency` / `prefers-contrast` 四套 media query 生效
- [ ] Dynamic Type 放大到 AX 档时布局重排不截断（原型用 `font-size` 变量模拟）
- [ ] 弹层有焦点陷阱、Esc 关闭、关闭后焦点回到触发元素
