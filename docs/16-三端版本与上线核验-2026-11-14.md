## 2. 数据准确性：库内值 = 从原始记录重新走一遍

这是最关键的一组。做法是**不调用生产函数**，用一段独立 SQL 从 `activities` 逐日推进 EWMA（CTL 42 天、ATL 7 天、ACWR 0.25/0.069），再逐日比对库内 `daily_metrics`：

| 检查项 | 结果 |
|---|---|
| 负荷 / EWMA 与独立重算一致 | 14 天，超差 0；最大偏差 CTL 0.0005、ATL 0.0005（仅 4 位小数的舍入差） |
| 重算幂等（同输入同输出） | 140 行，变化 0 / 消失 0 / 新增 0 |
| TSB = 前日 CTL − 前日 ATL | 14 天，违例 0 |
| **休息日状态量下降** | 3 个休息日，ATL / CTL 逆势上升 0（连休不降会让 TSB 永远为负、就绪度继续建议加量） |
| 数值无 NaN / 越界 | 非有限 0、ACWR 越界 0、就绪度越界 0 |

> 说明：`acwr.ewma` 不是 `ATL / CTL`，而是用 0.25 / 0.069 两个独立衰减常数算出的「急性/慢性」之比。所以核验用的是重走算法，而不是简单的比值等式——用比值去校验会得到 13 天「违例」的假警报。

## 5. 三端独立版本（本轮新增）

### 5.1 产物结构

```
dist/
  index.html          设备识别与分发页（同时是安装引导）
  version.json        版本号 + 核心文件指纹 + 三端清单
  iphone/             竖屏 · 单列 · 底部标签栏
  ipad/               横竖屏 · 双列 · 侧边栏
  mac/                桌面窗口 · 三列 · 侧边栏 + 顶栏
```

每个平台目录都自带：`index.html`、`manifest.webmanifest`、`sw.js`、`icons/`（180 / 192 / 512 / maskable）、以及 6 个 JS + 1 个 CSS。

构建：`npm run build`（`build/platforms.mjs`），**零第三方依赖**，图标由 `build/icons.mjs` 用 `node:zlib` 直接生成 PNG。

### 5.2 三个版本如何做到「独立且相互兼容」

| 维度 | 做法 | 可验证的结论 |
|---|---|---|
| 数据与算法 | 三个目录里的 `app.js` / `supabase-client.js` / `data.js` / `live.js` / `ui-flows.js` / `styles.css` / `env.js` **字节完全相同** | 构建脚本逐文件比对 sha256，输出「核心一致性：三个版本字节相同 ✓」；`dist/version.json` 里也记录了 `coreIdentical` |
| 独立安装 | 每个版本的 manifest 有各自的 `scope` 与 `start_url`（`/iphone/`、`/ipad/`、`/mac/`），service worker 缓存名也按平台区分 | 同一台设备可并存安装三个、各自更新与卸载，互不覆盖 |
| 设备识别 | `dist/index.html` 按 UA + `maxTouchPoints` 判断（含 iPadOS 13+ 伪装成 Mac 的情况），并用视口宽度兜底；识别结果高亮对应卡片，650ms 后自动跳转 | 实测 Mac 浏览器打开：识别为 Mac，高亮 Mac 卡片 |
| 装错版本 | 独立版启动时比对「预设平台」与「实际设备」，不一致就顶部给一条可点的切换提示（9 秒自动退场） | 实测：在 Mac 上打开 iPhone 版，出现「当前打开的是 iPhone 版，检测到本机为 Mac」 |
| 布局锁定 | `window.ARC_PRESET` 在 `app.js` 之前注入，锁定平台并隐藏预览用的顶栏与设备边框 | 实测：iPhone 版无设备画框、无控制台，铺满视口，安全区留白 |
